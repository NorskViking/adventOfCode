# Advent of Code
Solved using the Rust language

## Start new puzzle
Initiate a new "day" puzzle, by running **cargo new** with day and the corresponding number, e.g. 1, 2, 3, etc.
**cd** into the **./src** in the new folder, create and add the puzzle to a new **puzzle.txt** file. 

```BASH
//initate new project
$ cargo new day{num}
$ cd /day{num}/src/

//create new puzzle.txt file
$ touch puzzle.txt 
//open file in VSC or from the terminal and add text
$ nano puzzle.txt
```

## Solve the puzzle
Follow the instructions given for the given day from [www.adventofcode.com]() to solve the puzzle.

### Test the code
To **build** and **run** the code, run:
```BASH
$ cargo build

$ cargo run 
```
